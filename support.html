常见问题

提醒没有响？ 在“设置 → 权限与状态”里确认通知已允许；闹钟类任务还需要允许“闹钟”。

怎么和家人互相提醒？ “家人”页 → 填写家人怎么称呼你 → 邀请家人，把消息发给对方；对方安装栗栗后复制整段消息，在“家人”页点“粘贴”即可。

怎么取消订阅？ iPhone“设置 → Apple ID → 订阅 → 栗栗 Plus”。

FAQ

Reminders don't ring? Check Settings → Permissions & status in Lili; alarm tasks also need the Alarms permission.

Remind each other? Family tab → set what family calls you → Invite family. They install Lili, copy the whole message and tap Paste on the Family tab.

Cancel a subscription? iPhone Settings → Apple ID → Subscriptions → Lili Plus.
